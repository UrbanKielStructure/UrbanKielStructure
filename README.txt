# URBAN KIEL STRUCTURE - Sitio web

Archivos incluidos:
- index.html
- styles.css
- script.js
- assets/

## Cómo publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta al repositorio.
2. Verifica que `index.html` esté en la raíz del repositorio.
3. En GitHub ve a Settings > Pages.
4. Selecciona la rama `main` o `principal` y la carpeta `/(root)`.
5. Guarda y espera el despliegue.
